OpenCart 4 · in detail

What a buyer does, and what the store does about it

The OpenCart extension is the one that has been installed, configured and exercised on a real 4.1.0.4 store end to end, so it is documented here in full. The other packages follow the same contract.

  1. Collect

    “Add to Quote” gathers products from product pages and category tiles into a list held in the browser — never in the OpenCart cart, so a buyer pricing a dozen items leaves their cart, shipping estimate and abandoned-cart email untouched.

  2. Ask

    A three-step panel takes the items, then the buyer's details, then confirms. Logged-in customers have their name, email and phone prefilled from the store; guests type them.

  3. Re-price server-side

    The panel posts product ids and quantities only. The extension re-reads name, model and price from the catalog and applies the store's own visibility rules, so a disabled product cannot be quoted by guessing its id.

  4. Land as a draft quote

    TackQuote creates a draft in the store's own currency for a seller to price and send back, and returns the reference the buyer sees.

Both directions, two separate secrets

  • Store → TackQuote. Quote requests are posted server-side with your TackQuote API key, so the key never reaches a page.
  • TackQuote → store. extension/tack/api/product.list, order.list and order.add, authenticated with a feed token you generate in the store.
  • Neither secret works in the other direction, and the feed refuses every request with a 503 until a token is set.

Known limits

  • OpenCart 4 only. 4.x resolves routes and autoloads differently from 3.x, and no 3.x package is shipped.
  • If a theme has renamed core's Add to Cart button (id="button-cart"), the inline buttons are skipped rather than injected on a guess — assign the module to a layout position instead.
  • A quote holds up to 50 distinct products, and one browser session may submit five requests per ten minutes.

Install & distribution

Where the packages come from

This repository is the distribution authority. Each platform's source sits in its own top-level directory, and every package is rebuilt from that source rather than edited in place.

Read first

The latest published release is v1.0.0 (1 Aug 2026). main is ahead of it — including the OpenCart work in the evidence table — so for anything newer than that release, take the source from this repository and build the package with the repository's own packaging script.

The OpenCart installer archive tack.ocmod.zip is not among the v1.0.0 assets at all; its README explains how to build it. The filename is load-bearing — OpenCart derives the extension code from it.

Getting a package

  • From a release. Download the ZIP for your platform from the Releases page and install it the way that platform installs extensions.
  • From source. Clone this repository and run its packaging script; the artefacts land in dist/extensions/.
  • Then connect it. Paste a TackQuote API key into the extension's settings screen and use its “Test connection” button — it calls the API rather than checking that a field is filled in.
